TAIWO EATS WEBSITE

HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract the taiwo_eats_website.zip file.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted taiwo_eats_website folder.
5. Open index.html.
6. To preview the website, right-click index.html and choose "Open with Live Server"
   (if the Live Server extension is installed), or open index.html in your browser.

FILES
- index.html: Homepage
- about.html: About page
- menu.html: Menu page
- contact.html: Contact page
- style.css: Styling for all pages
- script.js: Contact form interaction

NOTE
The contact form currently displays a confirmation message in the browser.
It does not send an email. A backend or form service is needed for real submissions.
The menu prices and contact details are sample content and can be edited.
Internet access is needed for the online images and Google Fonts.
